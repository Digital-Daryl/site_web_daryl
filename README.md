# DARYL | Solutions digitales pour entreprises

DARYL accompagne les entreprises, commerçants et restaurateurs dans leur
transition numérique. Ce dépôt contient le code source du site vitrine de
DARYL, qui présente ses offres et permet aux visiteurs de contacter
l'entreprise ou d'échanger avec son assistant virtuel.

## Services présentés sur le site

- **Assistant virtuel pour le support client** : chatbot intégrable à un site
  web ou à WhatsApp pour répondre aux questions fréquentes, gérer les
  réservations et faciliter les demandes clients.
- **Site web vitrine** : création d'un site professionnel et adapté aux
  mobiles pour présenter l'activité, les menus, les horaires et l'identité de
  marque.
- **Pack Digital Complet** : un site vitrine associé à un assistant virtuel.

Les tarifs affichés sur le site au moment de la rédaction de ce README sont :

| Offre | Mise en place | Frais mensuels |
|---|---:|---:|
| Assistant virtuel | 600 € HT | 30 € HT / mois |
| Site web vitrine (1 à 5 pages) | 900 € HT | 40 € HT / mois |
| Pack Digital Complet | 1 500 € HT | 70 € HT / mois |

Les tarifs et le détail des offres peuvent évoluer. Le site fait foi pour les
informations à jour.

## Le site

Le site est une page web responsive composée de trois sections accessibles
depuis la navigation :

- **Accueil** : présentation de l'activité de DARYL ;
- **Nos Services** : détail des offres ;
- **À propos** : présentation de l'entreprise.

Il comprend également un chatbot. À sa première ouverture, le navigateur
contacte le service distant du chatbot pour obtenir le message d'accueil de
l'agent. Les échanges utilisent un identifiant de session conservé dans le
navigateur.

## Technologies

- HTML pour le contenu et la structure ;
- CSS pour la mise en page et le responsive design ;
- JavaScript natif pour la navigation et les interactions du chatbot.

Le site ne nécessite pas d'étape de compilation ni de dépendances npm.
